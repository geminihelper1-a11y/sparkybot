# Spark v10 — practical command surface

`sp help` — public command guide
`sp help admin` — full admin control surface
`sp features` — feature overview
`sp smp` / `sp ip` — live SMP data
`sp profile @user` — member profile
`sp role <role> @user...` — bulk role assignment
`sp rolelist <role>` — role member list
`sp purge ...` — purge messages
`sp report @user <reason>` — private report
`sp ticket` — private ticket
`sp streak` / `sp board` — activity streaks
`sp suggest <idea>` — suggestion
`sp backup` / `sp backups` — server backup

## Natural-language operations

Mention Spark and ask for live server data or an explicit task. Spark can read current server/member/channel/role/VC/SMP/thread/event/invite/ban/emoji/audit-log data, and can on demand search Discord message history by user, channel, keyword and date range.

Permitted staff actions include sending/editing/deleting/pinning/reacting to messages, purging, roles, moderation, nicknames, locks, channels, invites, reminders, polls, giveaways, AFK, welcome/goodbye, autorole, leveling, starboard, automod, logging, autoresponders, custom commands and repeats.

Spark never bypasses Discord permissions and never claims a failed action succeeded.
